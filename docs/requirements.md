# 电影自动下载项目需求文档

## 项目概述
开发一个 Python 爬虫工具，自动从多个电影资源站爬取电影信息及下载链接，筛选最优链接后生成 Excel 汇总文档。

## 目标网站

### 网站1：中国高清网 (cnmkv.com)
- **URL**: https://www.cnmkv.com/
- **平台**: WordPress + Begin 主题
- **分类**: 欧美电影、国产电影、日韩电影
- **列表页**: 分页展示电影卡片，含缩略图+标题+日期
- **详情页URL格式**: `https://www.cnmkv.com/{数字ID}.html`
- **标题格式**: `{年份}{地区}{类型}片《{电影名}》高清下载`
- **下载链接类型**: 夸克网盘、百度网盘、迅雷网盘
- **夸克链接格式**: `https://pan.quark.cn/s/{提取码}`（经 `go.php?url=` 跳转包裹）
- **文件大小**: 部分链接标注版本（1080p、4K），无明确文件大小

### 网站2：高清族 (hdzu.cc)
- **URL**: https://www.hdzu.cc/
- **平台**: 自定义网站（Bootstrap 框架）
- **分类**: 按节点/类型分类
- **列表页**: 电影卡片展示，含缩略图+标题+质量标注+分类/评分/年份地区演员
- **详情页URL格式**: `https://www.hdzu.cc/t/{数字ID}`
- **分页方式**: AJAX 点击加载更多（`#getmore`）
- **电影信息字段**:
  - 年代（年份）
  - 产地（地区）
  - 类别（分类，如 剧情/喜剧）
  - 豆瓣评分
  - 导演、编剧、主演
- **下载链接类型**: magnet 磁力链接
- **文件大小位置**: 链接文本中 `[13.66GB]` 格式
- **下载链接格式**: `magnet:?xt=urn:btih:{hash}`

## 核心功能需求

### 1. 爬取电影下载链接
- 遍历两个网站的电影列表，进入每个电影详情页
- 提取所有可用的下载链接（夸克网盘 / 磁力链接）
- 解析电影基本信息：电影名、上映年份、分类

### 2. 链接筛选策略
- 如果一个电影有多个下载链接，选择**文件大小最小**的一个
- 网站1（cnmkv）需处理：同部电影可能有多个网盘链接（夸克/百度/迅雷），优先选择夸克链接
- 网站2（hdzu）需处理：同部电影可能有多个磁力链接（不同清晰度/大小），选择文件大小最小的

### 3. 生成 Excel 文档
- **输出字段**:
  | 字段 | 说明 |
  |------|------|
  | 电影名 | 电影中文名称 |
  | 上映年份 | 电影上映年份（如 2026） |
  | 电影分类 | 电影类型（如 剧情、喜剧、悬疑、恐怖等） |
  | 下载链接 | 筛选后的最优下载链接 |
  | 文件大小 | 链接对应的文件大小（如有） |
  | 来源网站 | cnmkv / hdzu |
  | 链接类型 | 夸克网盘 / 磁力链接 |

## 待确认问题

1. **网站2链接类型**: hdzu.cc 提供的是磁力链接而非夸克网盘，是否仍需要爬取？Excel 中是否记录磁力链接？
2. **爬取范围**: 是爬取全站所有电影，还是限制数量（如前100部）或指定分类？
3. **运行方式**: 一次性爬取，还是支持定时自动更新？
4. **重复处理**: 两个网站可能出现同一部电影，是否去重？以哪个为准？
5. **Excel输出**: 输出路径和文件名是否有特殊要求？

## 技术栈
- Python 3.x
- requests / httpx（HTTP请求）
- BeautifulSoup4 / lxml（HTML解析）
- openpyxl（Excel生成）
